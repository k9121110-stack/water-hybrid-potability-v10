# Датасет

Kaggle Water Potability дереккөзінен CSV немесе ZIP жүктеңіз:
https://www.kaggle.com/datasets/adityakadiwal/water-potability

Colab ноутбугындағы upload ұяшығы ZIP ішіндегі CSV-ді өзі шығарады. Бұл бумаға деректерді Git арқылы жібермеңіз.

Күтілетін бағандар: ph, Hardness, Solids, Chloramines, Sulfate, Conductivity, Organic_carbon, Trihalomethanes, Turbidity және Potability.
