# Ауыз су сапасын скринингтеу

№10 нұсқаға арналған гибридті жоба: сараптамалық тексерулер мен машиналық оқыту моделін біріктіріп, Kaggle Water Potability дерегіндегі Potability класын болжайды.

Бұл — оқу мақсатындағы скрининг. Нәтиже ауыз судың қауіпсіздігіне сертификат бермейді және зертханалық талдауды алмастырмайды.

## Дерек жиыны

[Kaggle Water Potability](https://www.kaggle.com/datasets/adityakadiwal/water-potability). CSV файлын немесе ZIP архивін Colab ноутбугындағы жүктеу ұяшығына беріңіз. Датасет репозиторийге қосылмайды; жүктеу нұсқаулығы data/README.md ішінде.

## Colab-та модельді оқыту

1. notebooks/water_hybrid_v10.ipynb файлын Google Colab-та ашыңыз.
2. Ұяшықтарды ретімен орындап, Kaggle ZIP архивін не CSV файлын таңдаңыз.
3. Соңында жасалған model.joblib файлын жүктеп, models/model.joblib жолына қойыңыз.

Метрика, EDA қорытындысы, қате мысалдары және есептегі скриншоттар тек нақты орындалған Colab нәтижесімен толтырылады.

## Орнату және іске қосу

Алдымен виртуалды орта жасаңыз (қаласаңыз), содан соң жоба түбірінде үш команданы орындаңыз:

1. `pip install -r requirements.txt`
2. `uvicorn api.main:app --reload`
3. Басқа терминалда: `streamlit run app/ui.py`

API құжаттамасы: http://127.0.0.1:8000/docs

API predict қызметін қолданар алдында models/model.joblib файлы болуы керек. Colab-та модельді оқытып алған соң ғана API жұмысқа дайын болады.

## Жоба құрылымы

- notebooks/water_hybrid_v10.ipynb — EDA, 3 алгоритм, 5-fold CV, threshold баптау және модель сақтау.
- src/rules.py — кіріс валидациясы және түсіндірілетін сараптамалық ережелер.
- src/decision.py — ереже → ML → кейінгі тексеру тізбегі.
- api/main.py — /health, /predict, /explain және SQLite журнал.
- app/ui.py — API-ға сұрау жіберетін Streamlit интерфейсі.
- tests/ — ережелер, API және шешім логикасына арналған 21 тест.
- models/model.joblib — Colab-тағы оқытудан кейін қосылады.

## Сақтық және шектеулер

pH, хлорамин, лайлылық шектері тек қосымша тексеру белгісі. Олар барлық елге ортақ қауіпсіздік шегі емес. Су сапасын жергілікті стандарттар мен зертханалық талдау анықтайды.

GitHub-қа Kaggle token, .env, датасеттің жеке көшірмесі немесе decision_log.sqlite3 журналын қоспаңыз. Есепке тек өз Colab орындауыңыздан шыққан мәндер мен скриншоттарды енгізіңіз.
